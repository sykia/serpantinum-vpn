# Как помочь

Полезны отчёты о работе на Arch Linux, поддержка других версий Happ, проверка
вертикальной панели, переводы интерфейса и новые VPN-адаптеры.

Перед изменениями прочитайте [архитектуру](docs/ADAPTERS.md), затем запустите
Python-тесты и синтетический тест Node.js. Не проверяйте disconnect на чужой
рабочей VPN-сессии. Для такого сценария используйте собственное тестовое окружение.

Для pull request опишите проблему, изменение и выполненную проверку.
Сохраните upstream-авторство и AGPL-3.0-or-later. Не добавляйте личные настройки,
подписки, базы или бинарники VPN-клиента.
