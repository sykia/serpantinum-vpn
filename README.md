Небольшое независимое дополнение для тех, кому нужен отдельный VPN-модуль в
[Serpantinum](https://github.com/ilyamiro/serpantinum). Пример и первый адаптер используют
[Happ](https://github.com/Happ-proxy/happ-desktop). Проект не является официальной
частью Serpantinum или Happ и не аффилирован с их авторами.

## Что умеет

- Показывает `VPN · страна` в панели и отдельный пункт **VPN** в настройках модулей.
- Сохраняет стиль, анимации и орбитальный интерфейс сетевого окна Serpantinum.
- Центральная кнопка отправляет Happ команду подключения или отключения.
- Показывает локации из локальной базы Happ: поиск, текущий сервер, сортировка и TCP-пинг.
- Настраивает запуск Happ после входа в графическую сессию и подключение к последнему серверу.
- Устанавливается в отдельную пользовательскую копию оболочки с резервными копиями и откатом.

Выбор сервера выполняется в самом Happ — в списке есть кнопка его открытия.
Happ не предоставляет VPN-подписку: сначала импортируйте свои серверы в клиент.
С другими VPN интерфейс можно использовать после реализации адаптера;
**в этой версии готов только адаптер Happ**. См. [архитектуру](docs/ADAPTERS.md).

## Совместимость

| Компонент | Версия / состояние |
| --- | --- |
| Serpantinum | **2.2.5-1**, ревизия `a304a330e4a32ab78f491a02fb9b4b06672d1760` |
| Happ для списка локаций | **4.4.8, Linux x86_64**; внутренний формат базы |
| Quickshell | 0.3.1 проверен в рабочей NixOS-сессии |
| NixOS + Hyprland | Исходный интерфейс проверен вживую; переносимый установщик проверен изолированно |
| Arch Linux + systemd | Переносимые пути и структура установки поддержаны; полноценного теста в Arch-сессии пока нет |
| Другие init-системы | `--no-systemd`: ручная интеграция запуска |
| ARM64 / другие версии Happ | Декодер локаций не поддержан в этом релизе |

Установщик проверяет исходные QML-файлы и структуру бинарника Happ до установки.
Если установлен другой Serpantinum, он остановится с объяснением, чтобы не перезаписывать
несовместимые файлы. Совместимость с будущими версиями не обещается.

## Установка

Нужны уже установленные Serpantinum и Happ, рабочий Quickshell, Python 3, Node.js и Bash.
Запускайте **своим обычным пользователем, без sudo**.

```bash
git clone https://github.com/sykia/serpantinum-vpn.git
cd serpantinum-vpn
bash install.sh --dry-run
bash install.sh
```

Можно скачать архив `serpantinum-vpn-0.1.0.tar.gz` из [релиза](https://github.com/sykia/serpantinum-vpn/releases/tag/v0.1.0),
распаковать его и запустить тот же `install.sh`.

На Arch дополнительные зависимости устанавливаются так:

```bash
sudo pacman -S --needed python nodejs git
```

На NixOS удобно запускать установщик с зависимостями из временной среды:

```bash
nix shell nixpkgs#python3 nixpkgs#nodejs --command bash install.sh --dry-run
nix shell nixpkgs#python3 nixpkgs#nodejs --command bash install.sh
```

Установка **не отключает VPN и не перезапускает Happ или оболочку**.
Новая оболочка и настройки автозапуска загрузятся при следующем входе в графическую сессию.
Немедленный выход из сессии не требуется. Автоподключение использует последнюю
выбранную локацию; автоматический выбор самого быстрого сервера не реализован.

Если пути не обнаружились, если уже есть локальная модификация или используется Home Manager,
смотрите [полную инструкцию с примерами](docs/INSTALL.md).

## Как пользоваться

1. Нажмите **VPN** на панели: страна и состояние находятся в центре окна.
2. Центральная кнопка включает или отключает VPN. Отдельной маленькой кнопки питания нет.
3. Откройте вкладку **Локации** и нажмите **Проверить пинг**.
4. Найдите сервер, отсортируйте список по задержке; для переключения откройте Happ.
5. В настройках Serpantinum → **Панель → Общие** можно переместить или убрать модуль VPN.

Задержка — время TCP-подключения к адресу и порту сервера через текущую сеть,
с учётом текущей маршрутизации. Это не ICMP-пинг, не тест скорости и не проверка
всего туннеля. Наличие процесса Xray тоже не гарантирует доступность интернета.

## Перезагрузка и обновления

Пользовательская копия хранится отдельно от системного пакета. Обновление обычного
Serpantinum не перезаписывает файлы модуля. На NixOS установщик создаёт GC roots
для необходимых пакетов, чтобы сборка мусора не удалила их.

Это также означает, что копия остаётся на своей версии: новые функции upstream
не появятся в ней автоматически. Для обновления дополнения требуется совместимый
релиз и перенос изменений. Не запускайте чужой несовместимый патч поверх этой копии.
После изменения внутреннего формата Happ чтение локаций может потребовать нового адаптера.

## Удаление

```bash
bash install.sh --uninstall --dry-run
bash install.sh --uninstall
```

Удаляются добавленные переопределения запуска и запись VPN в панели; другие настройки
панели сохраняются. Файлы, которые вы изменили после установки, не перезаписываются
молча. Резервные копии и снимок оболочки остаются на диске, пока работающая сессия
может их использовать. Подробности очистки и настроек Happ — в [инструкции](docs/INSTALL.md#удаление-и-восстановление).

## Что проверено

- Установка, предварительная проверка и удаление в изолированной домашней папке.
- Сохранение прав исполнения, откат файлов и символических ссылок.
- Добавление модуля без дублей; удаление с сохранением последующих пользовательских настроек.
- Идемпотентное изменение настроек автозапуска без изменения выбранного сервера.
- Чтение 26 реальных локаций в режиме read-only, без вывода реквизитов подключения.
- Проверка декодера на синтетической базе, отсутствие секретных полей в результате и отклонение неверного тега.
- Рабочий интерфейс статуса и локаций на NixOS / Hyprland.

Полный цикл «отключить → подключить» и реальная перезагрузка во время разработки
не выполнялись: приоритетом было сохранение работающего соединения. Первая версия
опубликована как **экспериментальная**. Вертикальная компоновка отдельно не проверена.
