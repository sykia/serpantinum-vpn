# Serpantinum VPN 0.1.0 — первый экспериментальный релиз

Отдельный VPN-модуль для Serpantinum с интеграцией Happ: состояние и страна
на панели, большая центральная кнопка, список локаций, поиск и TCP-пинг.

![VPN-панель](https://raw.githubusercontent.com/sykia/serpantinum-vpn/v0.1.0/docs/images/vpn.png)

## Быстрый старт

Скачайте `serpantinum-vpn-0.1.0.tar.gz`, распакуйте, откройте папку в терминале:

```bash
bash install.sh --dry-run
bash install.sh
```

Запускайте без sudo. Нужны уже установленные Serpantinum и Happ, Python 3,
Node.js, Bash и Quickshell. На NixOS:

```bash
nix shell nixpkgs#python3 nixpkgs#nodejs --command bash install.sh
```

На Arch дополнительные зависимости: `sudo pacman -S --needed python nodejs git`.

## В составе релиза

- Переносимый установщик для пользовательской копии shell.
- Проверка совместимости до внесения изменений.
- Сохранение прав скриптов, резервные копии и удаление с восстановлением.
- Автозапуск Happ и последнего сервера после графического входа.
- Nix GC roots для зависимостей, чтобы обновление/сборка мусора не убрали модуль.
- Русская документация, скриншоты и дополнительный английский README.

Установщик не выключает VPN и не перезапускает действующие службы.
Новая копия включится при следующем входе в сессию.

## Совместимость и ограничения

Поддерживаемая база: **Serpantinum 2.2.5-1**, ревизия
`a304a330e4a32ab78f491a02fb9b4b06672d1760`; декодер локаций —
**Happ 4.4.8 Linux x86_64**. Другие VPN требуют отдельного адаптера.
Список использует внутренний формат Happ, который может измениться.

Интерфейс проверен на NixOS / Hyprland, переносимый установщик — в изолированном HOME,
включая генерацию systemd-файлов через тестовый systemctl. Полная Arch-сессия,
реальная перезагрузка, вертикальная панель и полный цикл отключения/подключения
пока не проверены. Во время разработки работающее VPN-соединение сохранялось.

TCP-пинг использует текущую сеть и не является проверкой полного туннеля.
Выбор сервера выполняется в Happ. Снимок shell переживает обновления пакета,
но новые функции upstream автоматически в него не переносятся.
