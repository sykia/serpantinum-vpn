# Serpantinum VPN 0.2.0

Исправляет Super+D и маршрутизацию остальных команд к работающей оболочке.
Дополнение теперь накладывается на установленную версию Serpantinum при запуске,
сохраняет изменения upstream и остаётся на диске при обновлениях. Если точки
интеграции несовместимы, запускается обычная оболочка.

Добавлен выбор серверов по нажатию в мини-окне через необязательный нативный адаптер
Happ 4.4.8 / Qt 6. Адаптер нужно собрать с Qt клиента и передать установщику через
`--happ-bridge`. Он загружается при следующем обычном запуске Happ. Установка не
перезапускает клиент, не отключает VPN и не меняет выбранный сервер.

Ошибки управления отображаются в окне. Выбранный сервер учитывает подписку;
повторный выбор текущего сервера не отправляет команду. Пинг выполняется по кнопке.
Обновление дополнения: `bash install.sh --upgrade`.

Проверены установка/удаление, сохранение upstream, управление тестовым Qt-контроллером,
чтение синтетической базы и отсутствие управления VPN при опросе. В рабочей сессии
проверено сохранение PID Happ/Xray и выбранного сервера. Реальное переключение VPN
не выполнялось, поэтому нативный адаптер публикуется как экспериментальный.

Исходный архив содержит весь код адаптера и дополнения; бинарники Happ и данные
подписок не включены. Совместимость: Serpantinum 2.2.5-1, Happ 4.4.8 Linux x86_64.
